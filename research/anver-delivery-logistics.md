## 2. Доставка текстиля в Молдове

### 2.1. Доступные логистические партнёры в Молдове

#### FanCourier (текущий партнёр Anver)
- **Тип**: Курьерская доставка «до двери»
- **Покрытие**: Вся Молдова (включая Приднестровье)
- **Сроки**: 1–3 рабочих дня (Кишинёв — на следующий день)
- **Особенности**: Предварительный звонок курьера, SMS-уведомления, возможна доставка в субботу
- **Плюсы**: Надёжный, широкое покрытие, есть трекинг
- **Минусы**: Нет постаматов, нет самовывоза из пунктов

#### Poșta Moldovei
- **Тип**: Почтовые отправления
- **Сроки**: 3–7 рабочих дней
- **Стоимость**: Дешевле курьера (~30–50 лей за посылку)
- **Плюсы**: Покрытие 100% населённых пунктов
- **Минусы**: Медленнее, нет возможности проверки перед оплатой, посылка не «до двери»
- **Когда использовать**: Как альтернатива для отдалённых сёл, где FanCourier может не доставлять

#### Nova Poshta Moldova (международный оператор)
- **Тип**: Отделения / курьер / постаматы
- **Покрытие**: Кишинёв, Бельцы, Оргеев, Кагул, Унгены, Комрат — отделения; постаматы только в Кишинёве
- **Сроки**: 1–2 дня
- **Плюсы**: Быстро, есть мобильное приложение, push-уведомления
- **Минусы**: Ограниченное покрытие за пределами городов
- **Ценообразование**: ~60–80 лей по Молдове

#### Постаматы (Молдова)
- **Кто предлагает**: Nova Poshta (Кишинёв), небольшое количество в ТЦ
- **Статус**: Развиты слабо — большинство клиентов в Молдове предпочитают курьера или самовывоз
- **Рекомендация**: Для текстиля постаматы менее удобны — клиенту важно «пощупать» ткань, что невозможно в автоматизированной ячейке

### 3.3. Рекомендация: подключение онлайн-оплаты

**Оптимальное решение для Anver:**

1. **MaibPay** (если расчётный счёт в Maib) — самый популярный банк Молдовы, большинство клиентов имеют карты Maib.
   - Сайт: maib.md → Business → E-commerce
   - Документы: заявление, регистрационные документы SRL, договор
   - Интеграция: REST API — генерация платёжной ссылки, редирект на страницу банка, webhook для подтверждения

2. **2C2P** (если через Victoriabank) — поддерживает Apple Pay и Google Pay сразу.

**Техническая интеграция в Anver:**
- При нажатии «Оформить заказ» с выбранным методом «Онлайн»:
  1. Запрос POST /api/payment/create → создаёт заказ в БД + генерирует платёжную ссылку
  2. Редирект на страницу банка
  3. После успешной оплаты — редирект на /success?id=...
  4. Webhook от банка → обновление статуса заказа (paid/pending)

### 3.4. Что писать на сайте сейчас

- В корзине добавить селектор метода оплаты (хотя пока только наличные/картой при получении) — готовить UX

## 5. Оформление заказа (checkout flow)

### 5.1. Текущая воронка Anver

```
Корзина (drawer) → Форма (имя + контакт) → POST /api/order → /success?id=...
```

**Проблемы текущей реализации:**
1. Нет выбора способа доставки (только курьер)
2. Нет выбора способа оплаты (только при получении)
3. Нет поля «Адрес доставки» (имя + контакт — достаточно для созвона, но не для автоматизации)
4. Нет подтверждения заказа (сразу редирект на success)
5. Нет отслеживания статуса

### 5.2. Идеальная воронка заказа для текстиля

#### Шаг 1: Корзина → что показывать
- ✅ Список товаров с фото
- ✅ Количество, цена, удаление
- ✅ Итоговая сумма
- ✅ Индикатор бесплатной доставки (прогресс-бар: «Ещё 300 лей до бесплатной доставки»)
- ❌ Отсутствует: выбор доставки, выбор оплаты

**Рекомендация:** Добавить в корзину:
- Прогресс-бар «до бесплатной доставки»
- «Вам может понравиться» — 2–3 сопутствующих товара (наволочки к комплекту, простынь)
- Кнопка «Быстрый заказ» (только имя + телефон) и «Полный заказ» (с адресом)

#### Шаг 2: Форма заказа — обязательные поля

**Минимальный набор (быстрый заказ):**
- Имя (обязательно)
- Телефон (обязательно, валидация номера MD)
- Способ связи (Telegram / WhatsApp / Viber / Обычный звонок) — уже есть в форме контактов

**Полный заказ (добавить):**
- Адрес доставки (город, улица, дом, квартира)
- Комментарий к заказу
- Способ оплаты (наличные / картой / онлайн)
- Желаемое время доставки

#### Шаг 3: Подтверждение заказа

После нажатия «Оформить»:
1. POST /api/order (создание заказа в БД)
2. Ответ: `{ ok: true, id }`
3. Редирект на /success?id=...
4. Telegram-уведомление менеджеру ✅ (уже настроено)
5. **Рекомендация:** SMS-подтверждение клиенту (опционально)

#### Шаг 4: Страница «Спасибо» (/success)

**Что уже есть:**
- ✅ Номер заказа
- ✅ Что дальше (2 шага)
- ✅ Контакты для связи
- ✅ Уход за тканями

**Что добавить:**
1. ✅ Номер заказа (уже есть) — крупно, с опцией копирования
2. Детали заказа: состав, сумма, способ оплаты, адрес доставки
3. Статус: «Заказ принят → Ожидает обработки → Передан курьеру → Доставлен»
4. **Рекомендованные товары:** «К этому заказу часто берут» (наволочки, простынь другого размера)
5. **Кнопки действий:**
   - «Отслеживать заказ» (заглушка, пока нет трекинга)
   - «Вернуться на главную»
   - «Подписаться на Instagram»
   - «Рассказать друзьям» (ссылка на WhatsApp/Telegram с текстом)

#### Шаг 5: Послезакапное взаимодействие

| Время | Действие | Канал |
|---|---|---|
| Через 1 час | SMS: «Спасибо за заказ! Ваш номер: #...» | SMS-сервис (например, Twilio или местный) |
| При передаче курьеру | Уведомление + трекинг-номер | Telegram / SMS |
