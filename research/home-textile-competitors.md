## 1. Конкуренты в Молдове и Восточной Европе

### 1.1 Молдавские / румынские конкуренты

#### 1.1.1 Anver (сам сайт — база для сравнения)
- **URL:** anver.md (недоступен из рабочей сети, эталон — выгрузка Tilda)
- **Сайт:** Tilda → Next.js (текущая разработка)
- **Палитра:** тёмно-синий + терракота + стальной синий — консервативная, «домашняя»
- **Сильные стороны:** семейное ручное производство, 100% хлопок, 800+ довольных клиентов
- **Слабые стороны:** нет видео, нет 360°, нет калькулятора размера, каталог читает из хардкода/БД без умных фильтров, нет фильтрации по плотности ткани

#### 1.1.2 Lenk (Румыния)
- **URL:** lenk.ro
- **Специализация:** premium-постельное бельё, махровые полотенца, скатерти
- **Дизайн:** светлый, минималистичный (white space), пастельные тона (белый + серый + бледно-бежевый)
- **Структура главной:** Hero с крупным фото кровати, под ним — сетка категорий (плитки), ниже — преимущества (free shipping, linen quality, reviews)
- **Карточка товара:** галерея на 5–8 фото, увеличение при наведении (zoom), детальный выбор размера, калькулятор количества
- **Фишки:** видеообзоры тканей (60fps slow-mo — видно переплетение нитей), сертификаты Oeko-Tex, отзывы с фото, 15-day return
- **UX:** навигация sticky с поиском, фильтры по типу ткани, плотности, стране производства. Мобильная версия отличная (bottom nav для фильтров)
- **Цвета:** #ffffff, #2c2c2c, #c9a96e (золотой акцент), #f5f0eb (фон)

#### 1.1.3 Vivre Deco (Румыния)
- **URL:** vivre.ro (раздел Lenjerii de pat — постельное бельё)
- **Специализация:** мультибрендовый маркетплейс товаров для дома
- **Дизайн:** маркетплейс-стиль (плотная сетка, много инфы), цветовая палитра спокойная, акцент — зелёный
- **Карточка товара:** фото 1:1, цена жирно, скидка красным badge, состав в списке, кнопка "Adaugă în coș" крупная
- **Фишки:** кредит/рассрочка Stars — показана прямо на карточке, доставка 2–4 дня, но нет специализации на текстиле — общий каталог
- **Минусы:** нет видео, нет детальной инфы о ткани (плотность редко)

#### 1.1.4 Jumbo (Молдова / Румыния)
- **URL:** jumbo.md / jumbo.ro
- **Специализация:** товары для дома, включая текстиль (масс-маркет)
- **Дизайн:** яркий, оранжево-жёлтый, акцент на акции, крупные баннеры
- **Карточка товара:** базово (фото, цена, количество), без деталей о составе/плотности
- **Фишки:** цена и доступность в офлайн-магазинах — главное, доставка по всей Молдове
- **Вывод:** не прямой конкурент Anver (масс-маркет vs премиальное ручное производство)

#### 1.1.5 Maxico (Румыния)
- **URL:** maxico.ro
- **Специализация:** постільна білизна (bed linen), текстиль для дому
- **Дизайн:** flat-дизайн, иконки преимуществ, голубая палитра
- **Структура главной:** Hero (слайдер акций) → Категории → Хиты продаж → Преимущества → Подписка на новости
- **Карточка:** стандартная галерея, селектор цвета (миниатюры ткани), селектор размера с ценой, отзывы без фото

#### 1.1.6 Pro Textile (Румыния)
- **URL:** protextile.ro
- **Специализация:** оптовая и розничная продажа постельного белья, скатертей, полотенец
- **Дизайн:** утилитарный, функциональный — не дизайнерский, но удобный для опта (крупные таблицы размеров, скидки от объёма)
- **Фишки:** фильтрация по плотности (нити/см²) — редкая и ценная функция, таблицы размеров всех типов (евро, семейный, 1.5-спальный)
- **Карточка:** плохая галерея, нет zoom, зато исчерпывающие таблицы характеристик

#### 1.1.7 Dacian House (Румыния)
- **URL:** dacianhouse.ro
- **Специализация:** премиальный текстиль с этническими мотивами
- **Дизайн:** тёмный фон, винтажные орнаменты, тёплая палитра (бордо, золото, беж)
- **Карточка:** атмосферная галерея (постель в интерьере как произведение искусства), история коллекции, видео ткацкого процесса
- **Фишки:** сторителлинг (каждая коллекция — история), ручная вышивка как УТП

## 2. Дизайн и UX лучших сайтов текстиля

### 2.1 Общие принципы эталонного дизайна

1. **Белый / нейтральный фон** — акцент на товар, а не на дизайн сайта. 90% топ-сайтов (Brooklinen, Parachute, Snowe, Tou Project) используют white/off-white.
2. **Огромные фото** — товар занимает 60–80% экрана. Много воздуха вокруг.
3. **Единая тональность** — все фото одной цветовой гаммы (тёплые нейтральные или прохладные), без разнобоя
4. **Микро-копирайтинг** — короткие, содержательные заголовки ("Feel the difference", "Designed for deep sleep")
5. **Социальное доказательство** — рейтинг звёзд, "As seen in Vogue/Forbes", количество отзывов

### 2.2 Структура главной страницы (эталонная)

Усреднённая структура для премиального текстильного сайта:

  ┌──────────────────────────────────────────────────┐
  │ TOP BANNER: Free shipping $50+ | 15% OFF first   │ ← TopBanner (у Anver уже есть)
  │ HEADER: Logo | Shop (megamenu) | Search | Cart    │
  ├──────────────────────────────────────────────────┤
  │ HERO: Full-screen фото кровати + складки ткани    │
  │       H1: "The softest sheets you'll ever sleep in"│
  │       CTA: "Shop best sellers"                    │
  ├──────────────────────────────────────────────────┤
  │ BEST SELLERS / HITS — горизонтальный карусель     │
  ├──────────────────────────────────────────────────┤

  │  [Sateen]  [Ranforce]  [Linen]  [Cotton percale] │
  ├──────────────────────────────────────────────────┤
  │ BUNDLE & SAVE — комплекты со скидкой              │
  │ (2-3 карточки "Комплект из 3 предметов — 15%")   │
  ├──────────────────────────────────────────────────┤
  │ WHY US — 3 преимущества в ряд + иконки            │
  │  [Premium cotton] [Handmade] [365-day trial]     │
  ├──────────────────────────────────────────────────┤
  │ AS SEEN IN / PRESS — логотипы изданий             │
  ├──────────────────────────────────────────────────┤
  │ INSTAGRAM — лента фото с @mention                 │
  ├──────────────────────────────────────────────────┤
  │ NEWSLETTER — подписка на скидку 10%               │

**Anver сейчас:** Hero → Преимущества → 3 каталога (постельное, сатин, ранфорс) → "О нас" → Контакты. Рекомендуется расширить.

### 2.3 Навигация и каталог

**Эталонная навигация:**

| Элемент | Лучшая практика |
|---------|-----------------|
| Megamenu | Brooklinen/Parachute — при наведении на "Shop" выпадают категории с фото |
| Фильтры | Category + Fabric + Size + Price + Color + Thread Count + Feature (cooling, wrinkle-free) |
| Сортировка | Popularity, New Arrivals, Price Low→High, Price High→Low, Rating |
| Поиск | Автодополнение с фото товара (Parachute, IKEA) |
| Hover на каталоге | Второе фото (товар крупно) + "Quick add" (Brooklinen) |

**Anver сейчас:** простая панель категорий (t978) — "Категории" и "Ткани". Без фильтров. Без поиска.

### 2.4 Мобильная версия

**Ключевые приёмы топ-сайтов:**
- Sticky bottom bar (Home / Search / Cart / Account) — стандарт 2025–2026
- Sticky "Add to Cart" на карточке товара (Brooklinen — кнопка всегда видна)
- Карусель на главной вместо сетки (карточки, которые можно листать по горизонтали)
- Collapse-секции (аккордеон для характеристик, отзывов, доставки)
- Bottom sheet для фильтров (выезжает снизу, не перегружая экран)
- Swipe по фото в галерее (а не стрелки)

### 4.3 Фотография: стиль съёмки

**Тренды 2025–2026:**
1. **Lived-in / Wabi-sabi** — не идеально заправленная кровать, а «мятая» постель с естественными складками. Выглядит уютно и честно (Parachute, Tou Project)
2. **Soft natural light** — без жёстких студийных вспышек, только естественный свет (золотой час)
3. **Texture close-ups** — макро-съёмка ткани, где видно каждую нить (Snowe, OkiOki — микроскоп)
4. **Flat lay** — съёмка сверху: комплект разложен на полу/кровати. Чисто, информативно (IKEA, Brooklinen)
5. **Colour consistency** — все фото в рамках одной коллекции должны быть сняты при одном освещении и на одном фоне
6. **Человек в кадре** — руки, гладящие ткань, человек укутанный в одеяло. Эмоция (Parachute, Society of W.)
7. **Видео-драпировка** — ткань в движении (slow-motion 60fps): струится, блестит, мнётся — лучше всего показывает качество

**Рекомендация Anver:** переснять фото в едином стиле (сейчас фото из Tilda — разного фона и освещения). Добавить макро-съёмку ткани (можно смартфоном + макро-линза). Снять 2–3 видео драпировки.
