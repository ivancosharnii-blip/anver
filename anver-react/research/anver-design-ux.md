## 2. Лучшие практики главной страницы для магазина текстиля

Структура идеальной главной страницы для Anver, основанная на паттернах лидеров рынка:

### 2.1. Hero-секция

**Что работает лучше всего:**
- **Вариант А (максимальная конверсия):** Полноэкранное лайфстайл-фото постели тёплом интерьере + короткий заголовок (2-4 слова) + одна CTA-кнопка.
- **Вариант Б (сторителлинг):** Видео-фон (10-15 сек цикл: как стелют постель, струящаяся ткань) + наложение текста.
- **Вариант В (акционный):** Как текущий Anver — фото + скидочное предложение + таймер.

**Рекомендация для Anver:**
Текущий hero (720px фото + заголовок + скидка) — хорошая основа. Улучшения:
1. **Добавить микроанимацию:** Заголовок появляется с fade-in, CTA — с задержкой
2. **Сделать CTA более контрастной:** Сейчас белая кнопка на светлом фоне может теряться
3. **Добавить социальный сигнал:** «★★★★★ 800+ довольных клиентов» прямо под CTA (не в футере)
4. **Сменить фото на тёплое интерьерное** (постель застелена, уютный свет, натуральные материалы)

### 2.2. Категории / коллекции

**Паттерн:**
- Сетка 3-4 карточки с крупными фото категорий
- Подпись ткани/коллекции + короткое описание (15-20 слов)

**Текущий Anver:** ❌ Нет блока категорий на главной — каталоги идут сразу сеткой товаров.

**Рекомендация:** Добавить секцию категорий перед каталогом:
```
[Ранфорс]   [Сатин]   [Сатин Страйп]   [Кухня]
  100% хлопок   Премиум   Полоски    Скатерти
```

### 2.3. Бестселлеры / новинки

**Паттерн:**
- Карусель или сетка из 4-8 товаров с бейджами «Хит», «Новинка», «Скидка»
- Фильтр по типу (бестселлеры / новинки / акции)

**Текущий Anver:** 3 каталога по ткани, товары внутри — да, но нет выделенного блока бестселлеров.

**Рекомендация:** 
- Добавить секцию «Хиты продаж» с 4-8 товарами, отсортированными по популярности
- В админке добавить поле `is_bestseller` / `is_new`

### 2.4. О бренде / производстве (сторителлинг)

**Паттерн:**
- 2 колонки: текст + фото производства / семьи
- Акцент на ручной работе, качестве, локальности

**Текущий Anver:** ✅ Блок «Немного о нас» есть. Хороший контент (семейное производство, Молдова).

**Улучшения:**
1. **Сделать более визуальным:** Добавить 3-4 фото процесса (ткацкий станок, руки, упаковка)
2. **Добавить числа:** «15 лет на рынке», «5000+ довольных клиентов», «100% хлопок»
3. **Добавить видео:** 30-сек ролик производства

### 2.5. Преимущества (доставка, качество, возврат)

**Паттерн:**
- 4 иконки с текстом: «Бесплатная доставка», «100% хлопок», «Лёгкий возврат», «Ручная работа»
- Расположение: сразу после hero ИЛИ перед футером

**Текущий Anver:** ✅ 4 преимущества на hero (доставка, ручная работа, возврат, Oeko-Tex). Классное решение — прямо поверх фото.

**Улучшения:**
- Сделать иконки более современными (единый стиль, обводка 1.5px)
- Добавить микроанимацию появления при скролле

### 2.6. Отзывы / социальное доказательство

**Паттерн:**
- Карусель отзывов с фото клиентов и звёздами
- Или / Instagram-лента (@anver.moldova)

**Текущий Anver:** ❌ Нет отзывов на главной. Рейтинг «800 довольных клиентов» — в футере.

**Рекомендация:**
1. **Вынести рейтинг на hero** (под CTA или в преимущества)
2. **Добавить блок отзывов** (3-5 отзывов с фото, можно захардкодить)
3. **Интегрировать Instagram-ленту** (через JS-виджет или ручную подборку 6 фото)
4. **Форма отзыва** — после покупки (уже есть `/feedback`)

### 2.7. Рассылка / подписка

**Паттерн:**
- Email-подписка со скидкой 5-10% за подписку
- Расположение: перед футером

**Текущий Anver:** ❌ Нет формы подписки.

**Рекомендация:**
- Добавить секцию перед футером: «Подпишитесь и получите скидку 5% на первый заказ»
- Интегрировать с email-маркетингом (SendPulse / UniSender для MD)

## 4. Визуальный контент

### 4.1. Фотография: какие фото конвертируют лучше

| Тип фото | Конверсия | Где использовать | Примеры |
|----------|-----------|-----------------|---------|
| **Тёплый интерьер** (постель застелена, уют, дневной свет) | ⭐⭐⭐⭐⭐ | Hero, карточка (второе фото) | Пастельная постель + деревянная мебель + зелень |
| **Flat lay** (сверху, постель расстелена) | ⭐⭐⭐⭐ | Каталог, первое фото | Красиво сложенный комплект + декор |
| **Белый фон** (только продукт) | ⭐⭐⭐ | Поиск, сравнение | Чистый предмет — для чёткого показа расцветки |
| **Деталь ткани** (макро, текстура) | ⭐⭐⭐⭐ | Модалка, зум | Крупный план переплетения нитей |
| **На человеке** (модель) | ⭐⭐⭐⭐⭐ | Карточка (hover) | Постель с человеком — масштаб |

**Текущие фото Anver:** Судя по галереям — есть flat lay и интерьерные фото с моделью. Это хорошо.

**Рекомендация:**
1. **Стандартизировать первое фото:** все товары — flat lay на бежевом фоне
2. **Второе фото:** интерьерное (постель на кровати)
3. **Третье фото:** макро текстуры ткани
4. **Добавить видео:** 15-сек распаковка / как стелить

### 4.2. Иконки: стиль

| Аспект | Текущий Anver | Рекомендация |
|--------|---------------|--------------|
| **Стиль** | Фото-иконки (через теги `<img>`) на hero. Кнопки контактов — фото с tildacdn / Supabase Storage | Перейти на SVG-иконки единого стиля |
| **Толщина** | Разная | **Linear** (обводка 1.5-2px), скруглённые углы — подходит к Nunito |
| **Цвет** | Зависит от контекста | На hero — белые, в футере — #525252, в преимуществах — основной цвет |
| **Набор** | Нет единого сета | Создать набор: delivery, handmade, returns, cotton, phone, whatsapp, telegram, viber, instagram, size, composition, care |

### 4.3. Микроанимации

| Элемент | Текущий Anver | Рекомендация |
|---------|---------------|--------------|

## 6. Конкретные улучшения для текущего дизайна Anver

### Улучшение 1: Аккордеон с деталями товара (состав, уход, размеры, доставка)

**Что сделать:** Заменить блок `text` (HTML) в модалке на аккордеон с 4 раскрывающимися секциями.

**Где:** `components/ProductModal.tsx`

## 9. Пробелы и ограничения исследования

1. **Live-доступ к сайтам:** Анализ эталонных брендов выполнен по памяти (training data), а не через live-загрузку страниц. Конкретная вёрстка/цвета могут незначительно отличаться.
2. **Локальный рынок MD/RO:** Точный обзор молдавских и румынских сайтов текстиля требует webfetch, который недоступен. Рекомендации по конкурентам — из общей осведомлённости.
3. **Instagram @anver.moldova:** Реальная лента не проанализирована. Рекомендации по интеграции — общие.
4. **Конверсионные данные:** Рекомендации основаны на отраслевых бенчмарках, не на A/B-тестах Anver.
